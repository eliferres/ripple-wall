# Example agent setup

A deliberately small, fictional agent setup: two agents, a shared system
prompt, a model roster, docs, and a CI matrix. It exists so the
walkthrough in the repo README runs against real files.

Nothing here is a working agent. The point is the shape: one fact
written down in several places, which is exactly the shape the wall
guards.

## The house rules

Mirrored from `prompts/system-prompt.md`:

- Read before you write.
- Cite every file you touch.
- Stop and ask when the spec is ambiguous.
